# Writer: notes for agents

Writer is a Tauri app: Rust in `src-tauri/` does the work, React in `src/` is the UI. `docs/how-it-works.md` describes every part; read it first.

- `just check`: typecheck, JS tests and Rust tests. Run it before committing.
- `just dev`: the app with hot reload. Editing anything under `src-tauri/` (guides included) rebuilds and restarts it, killing imports and builds under way: never edit there while a job runs.
- When the user gives script feedback and asks the agent to fix it, promptly apply and verify the fixes, then share the new script version on the existing feedback.spheceo.com review link and confirm it is available. Save the feedback and the outcome in `docs/feedback/`, consolidated by category/topic per its README, with the review link and script/version references, so it feeds the training rounds every 2–3 days.
- Every key lives on writer-relay (`relay/`). People sign in at accounts.spheceo.com (`src-tauri/src/account.rs`), and the relay answers only their access token, per permission (`relay/src/auth.ts`). The old team token (`CLIENT_TOKEN` / `WRITER_RELAY_TOKEN`) was retired on 2026-10-23 and is in old public DMGs: never bring it back or build any token into the app.
- What someone may do is the capability ids in their token (`relay/src/manifest.ts` publishes them; ids are forever, rename labels only). Writer enforces them in `src-tauri/src/can.rs` (the real gate: commands, imports, jobs, HTTP routes) and `src/can.ts` (what's shown). A new feature that writes or shares a script goes through `can::` too.
- Claude: `claude.rs` asks through the Agent SDK sidecar (`sdk`, everyone's since Oct 24 2026 and no longer a choice in Settings: `agent.rs` runs `sidecar/`, as Edit's `baseOptions`, pinned to Edit's SDK version; a footage build then goes in steps, `steps.rs`, with Writer's MCP tools) or through `claude -p` (`cli`, only with `WRITER_ENGINE=cli` or `claude::with_engine`, for comparisons). Keep both paths giving the same checks: per-item ones live in `claude::item_clip`, whole-plan ones in `compile_with`/`off_target`.
- The relay's secrets are in Infisical (Repack's project, `dev`, `/writer-relay`), pushed with `just relay-secrets`. Never print one, pass one as an argument, or write one to disk. Leave Repack's `/convex`, `/media`, `/footage` and `/web` folders alone.

## Releases and self-update

Builds are named by their tag everywhere ("Writer v0.0.0", "Writer nightly-1": Settings, the log, the update pill, release titles). Versions go up a patch at a time (v0.0.0 is the first, then v0.0.1, …), never minor or major. **Never move to a new version (`just publish`) unless the user says so**, each time: an agent ships nightlies, not versions.

- `just nightly` (everything committed on `main`): tags main's head `nightly-<N>` (the next number) and pushes. The release workflow builds it and publishes it as a GitHub pre-release, so `releases/latest` (Stable) never sees it.
- `just publish` (everything committed on `main`): runs the checks, releases the current version if it was never tagged, otherwise bumps the patch in `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock` and `package.json` (committed as "Release vX.Y.Z"), and pushes it with its `vX.Y.Z` tag.
- `.github/workflows/release.yml` builds Writer.app for Apple Silicon and Intel (`scripts/package-app.sh`), the update zip `Writer-<target>.zip` (+ `.sha256`) and the disk image `Writer-<Apple-Silicon|Intel>.dmg`, and publishes the draft release once both are up. Run by hand, it makes a test build (workflow artifacts, no release).
- Signing: with the repo secrets `MACOS_CERTIFICATE` (Developer ID Application .p12, base64) and `MACOS_CERTIFICATE_PASSWORD`, everything in Writer.app is signed with the Developer ID under the hardened runtime (`scripts/writer.entitlements`); with `NOTARY_KEY` (App Store Connect API .p8, base64), `NOTARY_KEY_ID` and `NOTARY_ISSUER`, the disk image is notarised and the ticket stapled to it and the app. Without them it's all ad hoc. Nothing secret is built in: a downloaded Writer asks its person to sign in.
- The repo is public: installed Writers read GitHub Releases directly, no token (`src-tauri/src/update.rs`). Nightly, the default channel, offers whatever was published last; Stable only `releases/latest`; never a downgrade. The pill installs the update zip (checked against GitHub's SHA-256, its signature and team checked, the whole app swapped in) and restarts. Only release builds inside Writer.app update themselves.
